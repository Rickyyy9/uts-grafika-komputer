1. OpenGL Dasar & Komponen

OpenGL · GLFW · GLAD · GLSL · Context
1
PILIHAN GANDAApa fungsi utama OpenGL menurut materi?
AMembuat window, context, dan menerima input dari user
BLibrary level rendah untuk membuat program graphics 2D/3D; melakukan rendering ke frame buffer
CMemuat fungsi OpenGL versi tertentu saat runtime
DBahasa shader yang berjalan di GPU
OpenGL = library/API rendering level rendah yang melakukan rendering ke frame buffer, bukan langsung ke layar. Pembuatan window = tugas GLFW.
2
PILIHAN GANDAManakah peran GLFW yang benar?
AMemuat fungsi OpenGL saat runtime
BMulti-platform library untuk membuat window, context, surfaces, serta menerima input/output
CMenyimpan index vertex
DMenjalankan kode shader di GPU
GLFW = window/context/input. Yang memuat fungsi OpenGL saat runtime adalah GLAD.
3
PILIHAN GANDAUrutan context dasar OpenGL yang benar adalah…
AglfwMakeContextCurrent → glfwInit → glfwCreateWindow
BglfwInit → glfwCreateWindow → glfwMakeContextCurrent
CglfwCreateWindow → glfwInit → glfwMakeContextCurrent
DgladLoadGLLoader → glfwInit → glfwCreateWindow
glfwInit() dulu, lalu glfwCreateWindow(...), baru glfwMakeContextCurrent(window). GLAD dipanggil setelah context current.
4
PILIHAN GANDAMengapa GLAD diperlukan dalam program OpenGL?
AKarena OpenGL tidak bisa membuat jendela
BKarena versi OpenGL beragam dan fungsi OpenGL hanya dapat dikenali/dipanggil saat runtime
CKarena shader harus dikompilasi di CPU
DKarena texture harus dibaca lebih dulu
GLAD = loader generator. Fungsi OpenGL tidak dikenali saat compile, jadi harus dimuat saat runtime setelah context tersedia.
5
PILIHAN GANDADi mana buffer dialokasikan oleh OpenGL context?
ADi dalam shader
BDi frame buffer layar
CDi GPU
DDi file shader .vs/.fs
Objek buffer adalah array memori tidak terformat yang dialokasikan oleh context dan disimpan di GPU.
6
BENAR / SALAHGLSL Shader Code berjalan di CPU agar pekerjaan grafis dialihkan.
Salah. Saat GLSL shader terpasang, pekerjaan pemrosesan graphics dialihkan ke GPU, bukan CPU.
7
BENAR / SALAHOpenGL langsung menggambar ke layar tanpa perantara frame buffer.
Salah. OpenGL melakukan rendering ke frame buffer, lalu kontennya dipakai untuk layar.

2. Koordinat & Viewport

NDC · sistem tangan kanan · glViewport
8
PILIHAN GANDAApa itu NDC?
AWarna normal objek (Normal Diffuse Color)
BNormalized Device Coordinates — koordinat yang dipakai vertex shader, contoh range −1 sampai 1
CNama fungsi OpenGL untuk menggambar
DMode texture wrapping
NDC = Normalized Device Coordinates. Vertex yang diproses di vertex shader harus dalam keadaan NDC (contoh −1..1).
9
PILIHAN GANDAPada window 800×600, titik NDC (0.5, 0.5) dipetakan ke koordinat layar…
A(800, 600)
B(200, 150)
C(400, 300)
D(0, 0)
Titik tengah = setengah dimensi → 800/2 = 400, 600/2 = 300 → (400, 300).
10
PILIHAN GANDAJika glViewport diberi (0, 0, w, h), posisi awal gambar berada di…
AUjung kiri atas
BUjung kiri bawah
CTitik tengah window
DUjung kanan bawah
glViewport(0,0,...) menempatkan titik awal di kiri bawah.
11
BENAR / SALAHOpenGL menggunakan sistem koordinat tangan kanan, dan untuk tampak 2D kedalaman dibuat sama dengan z = 0.
Benar. Sistem tangan kanan, dan z = 0 agar tampak 2D.
12
ISIAN SINGKATFungsi apa yang dipanggil di callback agar ukuran viewport menyesuaikan saat window di-resize? Tuliskan lengkap dengan parameternya.
glViewport(0, 0, width, height); — dipanggil di dalam framebuffer_size_callback(GLFWwindow* window, int width, int height), yang didaftarkan dengan glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);

3. Graphics Pipeline

Urutan 7 tahap
13
ISIAN SINGKATSebutkan urutan lengkap tahapan Graphics Pipeline.
Vertex Input → Vertex Shader → Primitive Assembly → Rasterization → Clipping → Fragment Shader → Output
14
PILIHAN GANDATahap yang mendiskritkan/memetakan primitive menjadi pixel adalah…
AVertex Shader
BPrimitive Assembly
CRasterization
DClipping
Rasterization memetakan primitive → pixel; memilih pixel yang berasosiasi dengan base color & depth.
15
PILIHAN GANDAApa yang dilakukan tahap Clipping?
AMengubah warna final pixel
BMembuang fragmen di luar fragmen/area yang ditentukan — dilakukan sebelum fragment shader
CMerakit vertex menjadi primitive
DMemuat data vertex dari buffer
Clipping membuang fragmen di luar area yang ditentukan, dijalankan sebelum fragment shader.
16
BENAR / SALAHFragment shader bertugas menghitung warna final pixel, termasuk efek cahaya dan bayangan.
Benar. Fragment shader = warna final pixel, mencakup warna dasar + efek cahaya/bayangan.
17
PILIHAN GANDADua shader yang disebut materi tetapi belum dibahas dan bersifat opsional adalah…
AVertex & Fragment Shader
BTessellation & Geometry Shader
CCompute & Ray Shader
DPixel & Depth Shader
Tessellation (interpolasi vertex mis. lingkaran smooth) dan Geometry shader (mis. riak air) — opsional, belum dibahas.

4. Vertex, VBO, VAO, EBO

Jangan ketuker!
18
PILIHAN GANDAApa yang disimpan oleh VBO?
AKonfigurasi atribut vertex
BData vertex pada memory GPU (array memori tidak terformat)
CIndex vertex
DWarna final pixel
VBO = data vertex (memory GPU). Konfigurasi atribut = VAO. Index = EBO.
19
PILIHAN GANDAApa yang disimpan oleh VAO?
AData vertex mentah
BKonfigurasi pointer/atribut vertex dari buffer
CSource code shader
DIndex untuk glDrawElements
VAO = konfigurasi/urutan atribut vertex; cukup bind saat menggambar.
20
PILIHAN GANDAFungsi EBO adalah…
AMenyimpan warna vertex
BMemuat fungsi OpenGL runtime
CMenyimpan index vertex (unsigned int) agar vertex sama tidak ditulis berulang
DMembangkitkan tekstur
EBO menyimpan index vertex bertipe unsigned int untuk glDrawElements.
21
ISIAN SINGKATTuliskan urutan setup VAO, VBO, dan EBO yang benar (nama fungsi).
glGenVertexArrays → glBindVertexArray → glGenBuffers → glBindBuffer → glBufferData → glVertexAttribPointer → glEnableVertexAttribArray
Urutan bind: VAO dulu, baru VBO (GL_ARRAY_BUFFER) & EBO (GL_ELEMENT_ARRAY_BUFFER), baru konfigurasi atribut.
22
PILIHAN GANDAFungsi glGenBuffers(n, &id) berfungsi untuk…
AMengikat buffer ke target
BMembangkitkan id buffer
CMencopy data ke buffer GPU
DMengaktifkan atribut vertex
glGenBuffers = bangkitkan id. glBindBuffer = ikat. glBufferData = copy data.
23
PILIHAN GANDAFungsi glBufferData(target, size, data, usage) pada materi memakai usage…
AGL_DYNAMIC_DRAW
BGL_STATIC_DRAW
CGL_STREAM_DRAW
DGL_FIXED_DRAW
Materi memakai GL_STATIC_DRAW untuk glBufferData.
24
BENAR / SALAHUrutan bind yang benar adalah VBO terlebih dahulu, baru VAO dan konfigurasi atribut.
Salah. Yang benar: ikat VAO dahulu, baru VBO/EBO, lalu konfigurasi atribut. (Jika VBO diikat sebelum VAO, harus diikat ulang.)

5. glDrawArrays vs glDrawElements

Tanpa index vs dengan index
25
PILIHAN GANDAManakah pernyataan yang tepat?
AglDrawArrays memakai index dari EBO; glDrawElements menggambar berurutan
BglDrawArrays menggambar vertex berurutan langsung dari VBO; glDrawElements menggambar melalui index di EBO
CKeduanya identik dan tidak ada perbedaan
DglDrawElements tidak membutuhkan shader
glDrawArrays = berurutan tanpa index (contoh: 3 vertex). glDrawElements = via index/EBO (contoh: rectangle, lebih efisien).
26
ISIAN SINGKATTuliskan baris kode materi untuk menggambar segitiga sederhana (3 vertex) dan menggambar rectangle dengan index.
Segitiga: glDrawArrays(GL_TRIANGLES, 0, 3);
Rectangle: glDrawElements(GL_TRIANGLES, sizeof(indices), GL_UNSIGNED_INT, 0);

6. Rectangle & Index

4 vertex → 2 triangle
27
PILIHAN GANDAMengapa rectangle cukup memakai 4 vertex posisi, bukan 6?
AKarena OpenGL membatasi maksimal 4 vertex
BKarena dua triangle berbagi vertex yang sama; index mengakses ulang vertex tersebut
CKarena rectangle tidak memiliki z
DKarena texture membutuhkan 4 titik UV
Rectangle disusun dari 2 triangle berhimpit. Dua triangle berbagi vertex → 4 vertex cukup, index mengakses ulang.
28
PILIHAN GANDAPerhatikan kode berikut.
unsigned int indices[] = { 0, 1, 2,  1, 2, 3 };
Apa isi indices tersebut?
A6 vertex posisi
BIndex untuk 2 segitiga: {0,1,2} segitiga 1 dan {1,2,3} segitiga 2
CNilai warna RGB
DKoordinat UV texture
indices[] memberi index unik vertex; 6 angka = 2 segitiga (masing-masing 3 index).
29
PILIHAN GANDAPerintah untuk mengaktifkan mode wireframe pada materi adalah…
AglPolygonMode(GL_FRONT_AND_BACK, GL_FILL);
BglPolygonMode(GL_FRONT_AND_BACK, GL_LINE);
CglLineMode(GL_FRONT_AND_BACK, GL_WIRE);
DglDrawElements(GL_LINES, ...);
Wireframe = GL_LINE; default model biasa = GL_FILL.
30
BENAR / SALAHEBO memakai target GL_ELEMENT_ARRAY_BUFFER dan penggambarannya dengan glDrawElements().
Benar. EBO → GL_ELEMENT_ARRAY_BUFFER, digambar dengan glDrawElements().

7. Struktur Array Vertex

stride · offset · location · glVertexAttribPointer
31
PILIHAN GANDAJika satu vertex berisi posisi + warna (6 float), berapa nilai stride-nya?
A3 * sizeof(float)
B6 * sizeof(float)
C8 * sizeof(float)
D2 * sizeof(float)
stride = jarak total antar awal atribut vertex berikutnya. posisi+warna = 6 float → 6*sizeof(float).
32
PILIHAN GANDABerapa offset awal atribut warna jika stride-nya 6*sizeof(float)?
A(GLvoid*)0
B(GLvoid*)(3*sizeof(float))
C(GLvoid*)(6*sizeof(float))
D(GLvoid*)(2*sizeof(float))
Warna mulai setelah 3 komponen posisi → offset = (GLvoid*)(3*sizeof(float)). Offset 0 untuk posisi.
33
ISIAN SINGKATJelaskan arti 6 parameter glVertexAttribPointer(index, size, type, normalized, stride, pointer).
index: lokasi atribut (0=pos, 1=color, 2=texCoord)
size: jumlah komponen (pos/color=3, texCoord=2)
type: tipe data (GL_FLOAT)
normalized: GL_FALSE pada materi
stride: jarak antar vertex (6*float atau 8*float)
pointer: offset awal atribut, mis. (GLvoid*)0
34
PILIHAN GANDAUntuk vertex berisi pos + warna + UV (8 float), bagaimana tiga pemanggilan glVertexAttribPointer yang benar?
Astride 3*float dengan offset 0, 3, 6
Bstride 8*float; index 0 offset 0 (size 3), index 1 offset 3*float (size 3), index 2 offset 6*float (size 2)
Cstride 6*float dengan tiga VBO terpisah
Dstride 2*float; semua index offset 0
Pos+warna+UV = 8*sizeof(float). Index 0: size 3, offset 0 · Index 1: size 3, offset 3*float · Index 2: size 2, offset 6*float.
35
BENAR / SALAHNilai index pada glVertexAttribPointer harus disamakan dengan layout(location=...) pada shader.
Benar. index/location adalah nomor lokasi atribut yang disamakan dengan layout(location=...) pada shader.

8. Shader & GLSL

in / out · gl_Position · FragColor · vec
36
PILIHAN GANDAVertex shader memproses vertex dan mengisi variabel…
AFragColor (vec4)
Bgl_Position (vec4)
CglViewport
Duniform mycolor
Vertex Shader → gl_Position (vec4). Fragment Shader → FragColor/fragColor (vec4).
37
PILIHAN GANDADalam GLSL, kata kunci in dan out berarti…
Ain untuk uniform, out untuk atribut
Bin menerima input, out mengirim output ke tahap berikutnya
Cin untuk CPU, out untuk GPU
DKeduanya sama saja
in = input, out = output. Output VS diterima FS dengan nama & tipe yang sama.
38
PILIHAN GANDAUntuk mengakses komponen ke-3 (z) dari variabel vec4 varku, sintaks yang benar adalah…
Avarku[3]
Bvarku.z
Cvarku.3
Dvarku.a
Komponen diakses dengan .x .y .z .w. Komponen ke-3 = .z.
39
ISIAN SINGKATJelaskan alur data komunikasi dari CPU sampai output FragColor (antara vertex & fragment shader).
CPU mengatur vertex attribute → vertex shader menerima in → vertex shader mengirim out → fragment shader menerima in (nama/tipe sama) → output FragColor.
40
PILIHAN GANDATipe vec2, vec3, vec4 adalah…
AInteger vektor berdimensi 2, 3, 4
BVektor float berdimensi 2, 3, 4
CTipe boolean matrix
DTipe string texture
vecn = vektor float berdimensi n. (integer = ivec, boolean = bvec.)

9. Compile & Link Shader

Urutan wajib
41
ISIAN SINGKATTuliskan urutan compile & link shader secara lengkap.
glCreateShader → glShaderSource → glCompileShader → glCreateProgram → glAttachShader → glLinkProgram → glDeleteShader
42
PILIHAN GANDAFungsi glCreateShader menerima parameter untuk membuat…
AGL_PROGRAM
BGL_VERTEX_SHADER atau GL_FRAGMENT_SHADER
CGL_ARRAY_BUFFER
DGL_TEXTURE_2D
glCreateShader(GL_VERTEX_SHADER) untuk VS, glCreateShader(GL_FRAGMENT_SHADER) untuk FS.
43
PILIHAN GANDAApa perbedaan shader object dan shader program?
AKeduanya sama, hanya beda nama
BShader object = hasil compile masing-masing VS/FS; shader program = hasil link yang menggabungkan keduanya dan dipakai glUseProgram()
CShader object berjalan di GPU, shader program di CPU
DShader program dibuat sebelum compile
Object = di-compile (VS/FS terpisah). Program = gabungan hasil link, dipakai dengan glUseProgram().
44
BENAR / SALAHglDeleteShader dipanggil setelah glLinkProgram untuk menghapus shader object.
Benar. Setelah link, shader object dihapus dengan glDeleteShader (sudah tidak diperlukan program).

10. Uniform

glGetUniformLocation · glUniform4f
45
PILIHAN GANDAApa keistimewaan uniform?
ABersifat lokal dan berubah tiap vertex
BBersifat global & unik per shader program; nilainya bertahan sampai di-update/di-reset
CHanya bisa dibaca oleh vertex shader
DDibuat otomatis tanpa deklarasi
Uniform = global, unik per shader program, nilainya bertahan sampai di-update/di-reset.
46
PILIHAN GANDABagaimana cara CPU mengubah nilai uniform?
AglBindBuffer lalu glBufferData
BglGetUniformLocation untuk dapat lokasi, lalu glUniform4f setelah glUseProgram
CglVertexAttribPointer index baru
DglTexImage2D
Alur: CPU → glGetUniformLocation() → glUniform4f() → shader membaca uniform (setelah glUseProgram di render loop).
47
BENAR / SALAHUniform dan in/out sama-sama mengalirkan data antar tahap shader.
Salah. in/out mengalirkan data antar tahap shader; uniform di-update dari program CPU ke shader program (beda mekanisme).

11. ShaderManager

readShader · GetInstance · compileAndLink · destroy
48
PILIHAN GANDAFungsi readShader() pada ShaderManager bekerja dengan cara…
AMengompilasi shader langsung ke GPU
BMembuka file shader dengan ifstream, membaca baris, menggabungkan ke string, lalu mengembalikan content
CMenghapus instance singleton
DMembangkitkan VAO
readShader() = baca file via ifstream, gabung ke string, return content.
49
PILIHAN GANDAApa yang dilakukan destroy() pada ShaderManager?
AMenghapus semua VBO dan texture
BMenghapus instance jika ada, lalu mengosongkan pointer instance
CMemuat ulang shader dari file
DMengembalikan id shaderProgram
destroy() = hapus instance (delete), set pointer instance = NULL.
50
ISIAN SINGKATTuliskan cara menggunakan ShaderManager (compile, ambil program, destroy).
ShaderManager::GetInstance()->compileAndLink("Test.vs", "Test.fs");
glUseProgram(ShaderManager::GetInstance()->getShaderProgram());
ShaderManager::GetInstance()->destroy();

12–16. Texture

UV · wrapping · filtering · mipmap · stb_image
51
PILIHAN GANDABerapa range koordinat texture (UV) pada materi?
A−1 sampai 1
B(0,0) sampai (1,1)
C0 sampai 255
D−0.5 sampai 0.5
Koordinat texture: (0,0) sampai (1,1). U & V = simbol koordinat texture.
52
PILIHAN GANDAApa bedanya UV coordinate dengan vertex coordinate?
AUV untuk posisi objek, vertex untuk gambar
BUV menunjuk posisi sampel pada gambar texture; vertex coordinate menunjuk posisi objek
CKeduanya sama persis
DUV hanya untuk objek 3D
UV = posisi sampel pada gambar texture; vertex coordinate = posisi objek.
53
PILIHAN GANDAMode wrapping yang membuat texture diulang lalu dibalik/flip adalah…
AGL_REPEAT
BGL_MIRRORED_REPEAT
CGL_CLAMP_TO_EDGE
DGL_CLAMP_TO_BORDER
GL_MIRRORED_REPEAT = repeat + dibalik. GL_REPEAT = ulang saja. GL_CLAMP_TO_EDGE = stretch ke border.
54
PILIHAN GANDAMode wrapping yang memberi warna pada area di luar texture adalah…
AGL_REPEAT
BGL_MIRRORED_REPEAT
CGL_CLAMP_TO_EDGE
DGL_CLAMP_TO_BORDER
GL_CLAMP_TO_BORDER = area di luar texture diberi warna border.
55
PILIHAN GANDAApa perbedaan GL_NEAREST dan GL_LINEAR?
ANearest menginterpolasi; Linear memilih pixel terdekat
BNearest memilih pixel terdekat; Linear menginterpolasi linier dari pixel terdekat
CKeduanya sama-sama mode wrapping
DNearest untuk 3D, Linear untuk 2D
GL_NEAREST = pixel terdekat. GL_LINEAR = interpolasi linier pixel terdekat. Keduanya filtering.
56
PILIHAN GANDAKapan MIN_FILTER dan MAG_FILTER dipakai?
AMIN untuk texture diperbesar, MAG untuk diperkecil
BMIN_FILTER saat texture diperkecil; MAG_FILTER saat texture diperbesar
CMIN untuk wrapping S, MAG untuk wrapping T
DKeduanya hanya untuk mipmap
MIN_FILTER = texture diperkecil, MAG_FILTER = texture diperbesar.
57
PILIHAN GANDAApa itu texel?
AJumlah maksimum texture per objek
BTexture pixel — nilai koordinat texture berupa float yang tidak bergantung resolusi
CNama lain untuk vertex
DFormat file gambar texture
Texel = texture pixel; koordinatnya float, tidak bergantung resolusi.
58
PILIHAN GANDASetiap texture mipmap berikutnya berukuran…
ASama besar
BDua kali lebih kecil dari sebelumnya
CDua kali lebih besar
DSetengah lebih kecil (0.5×)
Mipmap: setiap texture berikutnya dua kali (2×) lebih kecil dari sebelumnya.
59
PILIHAN GANDAMode mipmap yang menginterpolasi linier antara dua mipmap terdekat dan sampling juga linier adalah…
AGL_NEAREST_MIPMAP_NEAREST
BGL_LINEAR_MIPMAP_NEAREST
CGL_NEAREST_MIPMAP_LINEAR
DGL_LINEAR_MIPMAP_LINEAR
GL_LINEAR_MIPMAP_LINEAR = interpolasi linier antar 2 mipmap terdekat + sampling linier. (Keduanya "LINEAR".)
60
PILIHAN GANDAMengapa texture perlu di-flip vertikal (stbi_set_flip_vertically_on_load(true))?
AKarena PNG selalu terbalik
BKarena OpenGL mengharapkan y=0 di bawah, sedangkan gambar biasanya mulai dari atas
CKarena texture harus berukuran pangkat dua
DKarena mipmap membutuhkan flip
OpenGL mengharapkan y=0 di bawah; gambar (PNG/JPG) biasanya 0 di atas → perlu flip.
61
ISIAN SINGKATTuliskan urutan membuat texture dari membuat id sampai bind di render loop.
glGenTextures → glBindTexture → glTexParameteri → stbi_load → glTexImage2D → glGenerateMipmap → (render loop) glBindTexture
Lib pembaca image: SOIL atau stb_image.h.

Pasangan yang sering tertukar

PILIHAN GANDAFungsi mana yang mengirim data gambar ke texture 2D?
AglGenTextures
BglBindTexture
CglTexImage2D
DglTexParameteri
glTexImage2D = kirim data gambar ke texture 2D. glTexParameteri = atur wrapping/filtering.
63
PILIHAN GANDAFungsi yang mengatur wrapping/filtering texture adalah…
AglTexImage2D
BglTexParameteri
CglGenerateMipmap
DglBindTexture
glTexParameteri = mengatur TEXTURE_WRAP dan TEXTURE_MIN/MAG_FILTER.
64
PILIHAN GANDAManakah pasangan yang benar tentang GLFW vs GLAD?
AGLFW memuat fungsi OpenGL; GLAD membuat window/context
BGLFW membuat window/context dan event; GLAD memuat fungsi OpenGL saat runtime
CKeduanya membuat shader program
DKeduanya membaca file texture
GLFW = window/context/event; GLAD = memuat fungsi OpenGL runtime.
65
PILIHAN GANDAPerhatikan kode.
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE,
    6 * sizeof(float), (GLvoid*)0);
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE,
    6 * sizeof(float), (GLvoid*)(3*sizeof(float)));
Kode ini menunjukkan struktur array…

BInterleaved position-color dalam satu array (stride 6, warna di offset 3)
CArray dengan UV coordinate
DTexture mapping
Ini interleaved position + color dalam 1 array: stride 6*sizeof(float), warna di offset 3*sizeof(float).
66
PILIHAN GANDAManakah yang tepat tentang vertex vs fragment?
AVertex = data pixel, fragment = data simpul
BVertex = data simpul; fragment = semua data yang dibutuhkan untuk merender pixel
CKeduanya sama-sama output FragColor
DVertex hanya untuk 3D, fragment untuk 2D
Vertex = data simpul; fragment = data yang dibutuhkan untuk merender pixel.
