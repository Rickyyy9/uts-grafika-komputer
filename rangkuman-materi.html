Topik 01

Intro & Data Flow Pipeline

Terminologi · Kode default GLFW · GLAD · Alur data di GPU

Terminologi

Istilah Kunci

Window

Jendela utama aplikasi / kontainer aplikasi pada OS. GLFW Window = window untuk GLFW.

OpenGL Context

Objek yang membawa semua state/instance OpenGL. Menyimpan segala keadaan terkait OpenGL.

Objek Buffer

Objek OpenGL yang menyimpan array memori tidak terformat, dialokasikan oleh context (disimpan di GPU).

Shader / Kernel

Program spesial yang membawa data ke GPU. Di OpenGL ditulis dengan bahasa C (GLSL).

Kode Default GLFW

Alur Program GLFW

  • glfwInit() — inisialisasi GLFW
  • glfwCreateWindow(w, h, title, monitor, share) — buat window
  • glfwMakeContextCurrent(window) — tetapkan context GLFW
  • Loop selama !glfwWindowShouldClose(window)
  • glClear(GL_COLOR_BUFFER_BIT) — bersihkan window, set mode mask warna
  • glfwSwapBuffers(window) — tukar buffer depan/belakang (hindari kedip)
  • glfwPollEvents() — cek & proses event (mis. klik close)
GLAD (Alternatif GLEW)

Kenapa Butuh GLAD?

  • Versi OpenGL bermacam-macam → harus cocok dengan dukungan GPU
  • Fungsi OpenGL tidak dikenali saat compile, hanya saat runtime
  • Loader generator open source untuk OpenGL/GLES/EGL/GLX/WGL

Langkah Pasang

1. Buka glad.dav1d.de · 2. Pilih C++, OpenGL, profile core · 3. Generate · 4. Pindahkan folder glad & KHR ke include GLFW · 5. Copy glad.c ke project

// include paling awal, sebelum include lain
#include <glad/glad.h>

// letakkan setelah glfwMakeContextCurrent(window);
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)) {
    fprintf(stderr, "Failed to initialize GLAD");
    return -1;
}
Data Flow Pipeline

Data Mengalir 3 Tahap

UploadRAM → GPU
→
Prosesdi GPU
→
Outputke Screen

1. Upload

Data vertex ditransfer dari RAM ke memory GPU (buffer). Sebaiknya sekali saja karena besar. Kernel = shader.

2. Proses

Kernel di-instantiate per vertex. Tiap core GPU jalankan thread. Bersifat paralel → butuh compile/link dinamis saat runtime.

3. Output

Video card terhubung ke monitor; penggambaran ke layar ditangani langsung oleh GPU.

Topik 02

Graphics Pipeline

Graphics Pipeline

Tahapan Pipeline

→

→
Rasterization

FragmentShader

Vertex Shader

Memproses vertex data → VBO. Ubah koordinat 3D vertex ke koordinat 3D lain; bisa proses atribut dasar.

Shape Assembly

Mengambil vertex dari vertex shader & merakitnya jadi primitif (GL_POINT, segitiga, dll).

Rasterization

Mendiskritkan primitif → pixel pada layar. Memilih pixel mana yang berasosiasi dengan base color & depth.

Fragment Shader

Didahului clipping (buang fragmen di luar). Menghitung warna final pixel termasuk efek cahaya/bayangan.

+ Tessellation & Geometry Shader (opsional, belum dibahas) · OpenGL pakai sistem koordinat tangan kanan

Koordinat & Viewport

NDC & glViewport

Normalized Device Coordinates

Vertex shader harus output dalam NDC. Range koordinat OpenGL -1 s/d 1. Agar terlihat 2D, z = 0.

glViewport(x, y, w, h)

Memberi tahu OpenGL area menggambar. Titik (0,0) = kiri bawah. Contoh window (800,600), titik (0.5,0.5) dipetakan ke layar (400,300).

-0.5-0.50.0 0.5-0.50.0 0.00.50.0

← vertices NDC (x, y, z=0)

Buffer & Attribut

VBO, VAO, dan Menggambar

VBO — Vertex Buffer Object 
GLuint VBO;
glGenBuffers(1, &VBO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER,
   sizeof(vertices), vertices,
   GL_STATIC_DRAW);
VAO — Vertex Array Object 
GLuint VAO;
glGenVertexArrays(1, &VAO);
glBindVertexArray(VAO);
glVertexAttribPointer(0, 3, GL_FLOAT,
   GL_FALSE, 3*sizeof(float), (GLvoid*)0);
glEnableVertexAttribArray(0);
// Render loop
while (!glfwWindowShouldClose(window)) {
    glClear(GL_COLOR_BUFFER_BIT);
    glUseProgram(shaderProgram);
    glBindVertexArray(VAO);
    glDrawArrays(GL_TRIANGLES, 0, 3);
    glfwSwapBuffers(window);
    glfwPollEvents();
}
Kenapa VAO Penting

VAO = Konfigurasi Sekali

  • Banyak objek 3D, tiap objek punya banyak triangle & vertex
  • Tiap vertex bisa simpan posisi, koordinat tekstur, normal
  • VAO menyimpan urutan konfigurasi semua objek

Keuntungan

Saat mengkonfigurasi vertex attrib pointer, cukup panggil sekali. Saat ingin menggambar objek, cukup bind VAO yang sesuai — hemat & rapi.

Topik 04

Triangle Color Interpolation

Multi-VBO · Atribut warna · Interpolasi warna

Color Interpolation

Warna per Vertex

Vertex Data Baru

Tiap vertex simpan 3 nilai posisi + 3 nilai warna → butuh VBO id 1 (id 0 untuk posisi).

float colors[] = {
    1.0f, 0.0f, 0.0f,  // merah
    0.0f, 1.0f, 0.0f,  // hijau
    0.0f, 0.0f, 1.0f   // biru
};
Modifikasi Shader 
// Vertex Shader
layout(location = 0) in vec3 aPos;
layout(location = 1) in vec3 acolor;
out vec3 color;
// Fragment Shader
in vec3 color;
fragColor = vec4(color.x, color.y, color.z, 1.0);

Layout location 0 & 1 mengacu pada index vertex · hasil akhir = gradasi warna antar vertex

Setup Multi-VBO

Dua VBO dalam Satu VAO

// Dua VBO terpisah
GLuint verVBO, colVBO;
glGenBuffers(1, &verVBO); glBindBuffer(GL_ARRAY_BUFFER, verVBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glGenBuffers(1, &colVBO); glBindBuffer(GL_ARRAY_BUFFER, colVBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(colors), colors, GL_STATIC_DRAW);

// Keduanya dikonfigurasi di dalam VAO yang sama
glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, verVBO);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 0, (GLvoid*)0);
glBindBuffer(GL_ARRAY_BUFFER, colVBO);
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, 0, (GLvoid*)0);
glEnableVertexAttribArray(0);
glEnableVertexAttribArray(1);

Render tidak berubah · saat cleanup hapus kedua VBO: glDeleteBuffers(1, &verVBO); glDeleteBuffers(1, &colVBO);

Topik 05

Rectangle & EBO

Kotak dari 2 segitiga · 4 vertex · glDrawElements

Persegi Panjang

Kotak = 2 Segitiga Berhimpit

4
Vertex (bukan 6) — dipakai bersama
2
Segitiga penyusun kotak
1
VBO cukup (tak perlu tambah)

Masalah: Hardcode

Hardcode rawan bug. Ganti 9 * sizeof(GLfloat) menjadi sizeof(vertices).

Solusi: EBO

Simpan indeks vertex. 4 titik diakses via indeks unik untuk membentuk 2 segitiga.

Element Buffer Object

Indeks Vertex

Data Vertex + Indeks 
float vertices[] = {
 0.0f,-0.5f,0.0f,   // 0
 0.0f, 0.5f,0.0f,   // 1
 0.5f,-0.5f,0.0f,   // 2
 0.5f, 0.5f,0.0f }; // 3
unsigned int indices[] = {
    0,1,2,   // Segitiga 1
    1,2,3    // Segitiga 2
};
Setup EBO 
GLuint EBO;
glGenBuffers(1, &EBO);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER,
    sizeof(indices), indices,
    GL_STATIC_DRAW);

// Gambar:
glDrawElements(GL_TRIANGLES,
    sizeof(indices), GL_UNSIGNED_INT, 0);

Urutan: bind VAO dulu → baru EBO · EBO pakai tipe GL_ELEMENT_ARRAY_BUFFER

Wireframe & Struktur Array

Render Mode & Interleaved Array

Polygon Mode 
// wireframe
glPolygonMode(GL_FRONT_AND_BACK, GL_LINE);
// default / filled
glPolygonMode(GL_FRONT_AND_BACK, GL_FILL);

Panggil sebelum render loop.

Gabung Posisi + Warna 
float vertices[] = {
 //posisi        //warna
 0.0f,-0.5f,0.0f, 1.0f,0.0f,0.0f,

};
// stride 6, offset warna di index 3
glVertexAttribPointer(0,3,GL_FLOAT,GL_FALSE,

   6*sizeof(float), (GLvoid*)(3*sizeof(float)));
Topik 06

Shaders

GLSL · Layout input · Uniform · ShaderManager

Konsep Shader

Program di GPU

Terpisah

Program shader berjalan di GPU, terpisah dari program utama. Komunikasi hanya via input/output.

GLSL vs HLSL

OpenGL pakai GLSL, DirectX pakai HLSL. Ditulis seperti bahasa C, kuat untuk vektor & matriks.

Struktur

#version → input/output/uniform → main(). Di main() variabel diolah.

intfloatdoubleuintbool vecnbvecnivecnuvecndvecn

Akses komponen vektor: .x .y .z .w · contoh: vec4 v2 = vec4(v1, 0.0, 0.0);

Layout pada Input

layout(location = 0)

Fungsi Layout

Mendefinisikan bagaimana vertex data terorganisir. Kita beri lokasi metadata spesifik agar bisa mengatur atribut vertex dari CPU.

Contoh

location = 0 → nilai 0 dikirim OpenGL via glGetAttribLocation pada lokasi id ke-0.

// Vertex Shader — kirim warna ke fragment
#version 330 core
layout (location = 0) in vec3 aPos;
out vec4 vertexColor;
void main() {
    gl_Position = vec4(aPos, 1.0);
    vertexColor = vec4(0.0, 1.0, 0.0, 1.0);
}
Uniform

Kirim Data Langsung ke Shader

  • Shader "suka menyendiri" — komunikasi terbatas in-out
  • Uniform = kirim data tanpa mekanisme in-out
  • Sifat global & unik per shader program
  • Nilainya tetap sampai di-update/direset
Deklarasi Uniform 
uniform vec4 mycolor;
void main() {
    fragColor = mycolor;
}
// Animasi warna gelap→terang di render loop (setelah glUseProgram)
float timeValue = glfwGetTime();
float greenValue = sin(timeValue) / 2.0f + 0.5f;
int loc = glGetUniformLocation(shaderProgram, "mycolor");
glUniform4f(loc, 0.0f, greenValue, 0.0f, 1.0f);
ShaderManager (Singleton)

Rapikan Pembacaan Shader

Struktur Class

ShaderManager.h — deklarasi (singleton: instance, shaderProgram). ShaderManager.cpp — implementasi.

class ShaderManager {
    static ShaderManager* instance;
    unsigned int shaderProgram;
public:
    static ShaderManager* GetInstance();
    void compileAndLink(const char* vs, const char* fs);
    unsigned int getShaderProgram();
    void destroy();
};

Cara Pakai

// compile dari file .vs / .fs
ShaderManager::GetInstance()
  ->compileAndLink("Test.vs", "Test.fs");

// ambil program
glUseProgram(ShaderManager
  ::GetInstance()->getShaderProgram());

// hapus resource
ShaderManager::GetInstance()->destroy();

compileAndLink: readShader → glCreateShader → Source → Compile → glCreateProgram → Attach → Link → DeleteShader

Topik 07

Textures

UV mapping · Wrapping · Filtering · Mipmaps · Rectangle with texture

Konsep Texture

Gambar Pembungkus Model 3D

Apa itu Texture?

Gambar pembungkus model 3D. Berbentuk 2D (ada juga 1D/3D).

Loader

Butuh SOIL atau stb_image.h untuk baca file jpg/png.

UV Mapping

Memetakan tekstur ke setiap vertex objek. U & V = simbol koordinat tekstur.

(0,0)(0,1) (1,0)(1,1)

← koordinat UV per vertex

Wrapping & Filtering

Di Luar (0,0)–(1,1) & Interpolasi Texel

Texture Wrapping

  • GL_REPEAT — ulang sepanjang x & y (default)
  • GL_MIRRORED_REPEAT — seperti repeat tapi dibalik
  • GL_CLAMP_TO_EDGE — ditarik sampai border
  • GL_CLAMP_TO_BORDER — diberi warna di luar

Texture Filtering

  • GL_LINEAR — interpolasi linier piksel terdekat
  • GL_NEAREST — pilih piksel terdekat
glTexParameteri(GL_TEXTURE_2D,
  GL_TEXTURE_MIN_FILTER, GL_NEAREST);
glTexParameteri(GL_TEXTURE_2D,
  GL_TEXTURE_MAG_FILTER, GL_LINEAR);

Koordinat tekstur tidak bergantung resolusi, tapi nilai float (disebut texel)

Mipmaps

Tiap Level ½ Ukuran Berikutnya

  • Kumpulan tekstur; tiap tekstur berikutnya 2× lebih kecil
  • Mengatasi objek jauh agar fragmen warna tepat
  • Hemat memory (objek kecil tak pakai tekstur resolusi tinggi)
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
Jenis Mipmap

4 Mode Mipmap

GL_NEAREST_MIPMAP_NEAREST

Ambil mipmap terdekat + interpolasi tetangga terdekat.

GL_LINEAR_MIPMAP_NEAREST

Ambil level mipmap terdekat, sampel dengan interpolasi linier.

GL_NEAREST_MIPMAP_LINEAR

Interpolasi linier antara 2 mipmap + sampel tetangga terdekat.

GL_LINEAR_MIPMAP_LINEAR

Interpolasi linier antara 2 mipmap terdekat + sampel linier.

Fragment Shader Lanjutan

Campur Tekstur & Warna

Fragment Shader 
#version 330 core
out vec4 FragColor;
in vec3 color;
in vec2 TexCoord;
uniform sampler2D myTexture;
void main() {
    // tekstur × warna vertex
    FragColor = texture(myTexture, TexCoord)
        * vec4(color.x, color.y, color.z, 1.0);
}
  • Vertex attrib: 0=posisi, 1=warna, 2=texcoord
  • Stride 8 * sizeof(float)
  • Bind texture di render loop: glBindTexture(GL_TEXTURE_2D, texture)
  • Untuk gabung >1 tekstur: gunakan multiple texture unit
